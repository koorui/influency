# 成果凝练与管理者评价（兼容入口）

本目录保留旧名称，实际执行资源已集中于 [unified-impact-evaluation](../unified-impact-evaluation/SKILL.md)。执行时先阅读该入口，再按输入进入成果定位与建卡或管理者评价阶段；只完成用户或平台指定阶段。

- 凝练读取 [输入定位](../unified-impact-evaluation/references/input-resolution.md) 与 [专家执行规则第一节](../unified-impact-evaluation/references/expert-method.md)，确认对象、版本、本期新增和基本验证，保留十二字段成果卡及原文依据。
- 评价读取统一技能的 [当前标准](../unified-impact-evaluation/references/grading-standard-20260925.md)、专家执行规则全文与 [平台契约](../unified-impact-evaluation/references/platform-contract.md)。系统给出明确建议，不冒充专家认定。
- 脚本、Schema及运行资源均以统一技能目录为根执行；本目录旧参考文件仅为历史资料，不据此恢复第二套判级规则。

独立使用请保留这两个相邻技能目录，或直接使用完整的统一技能。不得调用本目录并不存在的 scripts 或 schemas，也不自行执行平台其他阶段、发布报告或发送消息。
