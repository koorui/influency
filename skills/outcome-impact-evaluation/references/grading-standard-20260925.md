# 当前判级标准

## 本平台执行口径（用户于2026-09-25补充）

本文件是当前 L1–L6 和 D1–D7 的优先标准，覆盖旧版真实任务即L1、仅浦江接入算D6的限制。
对已经定位且具有原始材料的成果，每次完成评价必须给出 L1–L6 之一、七个 G1–G5 等级和明确理由，不以初步评价、待确认、待核验或空值替代等级。
按已提供证据能够支持的状态判级，不为提高等级补造事实。L1只要求成果形成与基本有效性验证；真实任务作用是L2、独立外部使用是L3、多主体持续使用是L4、稳定基础能力是L5、改变研究或工作方式是L6。
缺少高等级依据时选择较低等级。某维度没有可用外部证据时以G1作为本轮材料范围的保守基档，明确“本轮证据未建立更高等级”，不能写成现实中绝对不存在使用或认可。G1可以没有该维度引文，但必须解释证据范围；G2及以上必须有对应依据。空材料或成果身份不明属于工单输入问题，不能编造L1报告。
七维是整体L级的证据层，保留现有逐维G1–G5成熟度供底稿检查，不求和、不平均、不机械换算L级。该Word并未另给完整G1–G5逐档表，现有G档细则在不冲突处沿用。
D6考察稳定流程、平台或组织能力的集成，不限定浦江国家实验室；内部设计、实际输入输出、反馈闭环和持续运行分开。D7考察独立第三方评测、专业采用或权威认可；正式论文/专利是公开产出，不能单独证明外部认可。公开不等于复用，关注不等于认可。
判级以本轮提交材料可证明的成果状态为依据；项目启动、阶段截止、成果事件发生和材料形成日期分别记载。内部回顾材料可支持明确的技术事实，日期缺项写入适用边界，不清空已有等级，也不把截止日后或日期不明事件倒推为截止日前事实。公开来源的历史时间审计仍保留。
报告先写最终等级和关键事实，再说明适用范围和未达到更高等级的原因。低置信度可以保留，但不替代等级。人工验收只决定是否接受报告，不是生成明确等级的前置条件。

## 用户提供的原文

科研成果六级影响力分级及理论依据

科研成果创新影响力评价方法

一、基本结论

综合科研影响评价、创新扩散、成果应用与变革性研究等相关理论，可以看到，科研成果的影响通常不是一步形成的，而是经历一个逐步发展的过程：

成果形成  →  实际使用  →  外部采用  →  持续扩散  →  成为基础能力  →  形成重大引领

据此，将科研成果影响力划分为六个阶段。六级并非照搬某一个现有标准，而是在已有理论和评价框架基础上，结合科研项目成果评价需要形成的操作性分级。

二、六级影响力分级

| 等级 | 含义 | 进入这一等级的关键条件 | 直观理解 |

| --- | --- | --- | --- |

| L1 成果形成与验证 | 成果已经形成，并完成基本有效性验证 | 有明确成果和验证结果，不只是方案、概念或在研工作 | 做出来了，也证明基本有效 |

| L2 局部作用验证 | 成果已经进入真实任务并发挥作用 | 在项目、合作任务或实际场景中真正被使用 | 开始真正干活了 |

| L3 外部应用验证 | 已出现独立外部主体采用 | 能说明谁在什么任务中如何使用，并有实际结果 | 别人也开始真正用了 |

| L4 专业方向显著影响 | 已超过单个案例，在一个专业方向形成持续影响 | 出现多主体、持续或重复采用，并产生后续研究或应用 | 一批同行开始持续使用 |

| L5 领域基础能力 | 成果成为领域稳定依赖的工具、数据、方法或平台 | 被长期、反复使用，并嵌入研究或工作流程 | 类似 BLAST，逐渐成为领域基础工具 |

| L6 重大引领影响 | 成果实质性改变领域原有的研究或工作方式 | 改变方法体系、研究范式、工作流程，或推动形成被广泛采用的评测、标准与治理方式 | 类似 AlphaFold、ChatGPT，改变了大家怎么做事 |



两个关键边界：

L3 → L4：从“有外部使用”走向“多主体、持续使用”。

L5 → L6：从“成为稳定基础能力”走向“改变领域原有的研究、工作、评测或治理方式”。

三、六级为什么这样分

1. 从“成果形成”到“实际使用”

Payback Framework 等科研影响评价框架明确区分科研产出、成果使用以及进一步产生的影响[1][2]。 成果“做出来”并不等于已经产生实际影响，只有进入真实任务并开始发挥作用，才从产出阶段进一步进入使用和影响阶段。

对应关系：L1 成果形成 → L2 实际作用 → L3 外部采用

2. 从“一次采用”到“持续影响”

创新扩散和实施研究进一步区分 adoption、penetration、sustainability 等不同状态[3][4]。 一个成果被外部团队使用一次，可以证明其具有外部可用性；只有出现多主体、重复和持续采用，才能说明影响已经超出单个案例。

对应关系：L3 外部采用 → L4 专业方向显著影响

3. 从“持续使用”到“稳定基础能力”

Normalization Process Theory 以及 RE-AIM 等框架进一步关注一项创新如何从“被采用”逐步进入日常工作，并长期保持和稳定嵌入[5][6] 。因此，L5关注的已经不只是“有多少人用”，而是成果是否成为其他研究和工作的稳定支撑。

对应关系：L4 持续影响 → L5 领域基础能力

4. 从“基础能力”到“重大引领”

NSF 关于 Transformative Research 的定义强调，真正具有变革性的研究可能改变对重要问题的理解，催生新的研究方向甚至新的研究范式[7] 。因此，最高一级不是L5的简单放大，而是看成果是否已经改变领域原有的研究方法、工作流程、评价标准或治理方式。

对应关系：L5 基础能力 → L6 重大引领

5. 六级不是简单按“数量”递增

科研影响还需要同时考虑影响的范围、深度和持续性。英国 Research Excellence Framework（REF）在科研影响评价中重点考察 Reach（影响覆盖范围）和 Significance（影响程度和重要性）。[8] 结合前述扩散和实施研究，实际判级还需要关注影响是否持续、是否存在独立外部证据。

因此，论文数、引用数、下载量、用户数等都可以成为证据，但不能直接换算成 L1-L6。

四、实际怎么判：六级之下需要证据支撑

六级回答的是“这个成果目前走到了哪一步？”。实际评价还必须回答“凭什么认为它已经走到了这一步？”。因此，在六级之下设置 D1-D7 七类证据，用于组织和核验判级依据。

D1-D7 是证据层，L1-L6 是状态层。

七维不是另一套分级，也不是简单加权计算六级，而是为六级判断提供不同方面的证据。

| 证据维度 | 主要看什么 | 代表性理论或评价依据 |

| --- | --- | --- |

| D1 问题解决与先进性 | 解决了什么问题，相对已有研究或方法推进到什么程度 | OECD《Frascati Manual》关于R&D的创新性要求；Stokes“巴斯德象限”关于基础理解与实际应用并重的研究模式。[9][10] |

| D2 原创与项目新增 | 哪些是真正原创的，哪些是项目实施后新增的 | Frascati Manual 的 novelty；创新政策评价中的 additionality，用于判断公共资助真正带来的增量。[9][11] |

| D3 学术影响 | 是否形成独立引用、学术跟进和后续研究 | DORA、Leiden Manifesto 强调围绕具体成果、结合多类证据开展负责任科研评价。[12][13] |

| D4 开放复用 | 代码、模型、数据、Benchmark 等是否被第三方真实使用和复用 | FAIR Principles 关于科研数据可复用性；DORA 关于软件、数据等多类科研产出的评价。[12][14] |

| D5 真实应用 | 是否进入真实任务并实际发挥作用 | Payback Framework；创新采用与实施研究。[1][3][4] |

| D6 主线集成 | 是否从孤立成果进入稳定流程、平台或组织能力 | Normalization Process Theory 关于嵌入和整合；RE-AIM 关于长期维持。[5][6] |

| D7 外部认可 | 是否存在独立第三方评测、专业采用或权威认可 | REF 关于多元影响证据的评价要求；DORA 关于定量与定性证据结合的原则。[8][12] |



在人工智能领域，这些证据可以进一步落到比较具体的形态：

• D4 开放复用：代码被第三方调用或修改、模型权重被用于下游任务、数据集被独立研究使用、Benchmark 被其他团队采用等。

• D7 外部认可：独立第三方评测、被权威机构或专业框架采用、进入标准或指南、被主流技术体系正式集成等。

需要特别区分：公开不等于复用，关注不等于认可。

例如，上传 GitHub、HuggingFace 本身只能证明成果已经公开；只有出现独立第三方的实际使用、集成或评价，才构成更强的影响证据。

实际判级时，首先判断成果是否跨过相应等级的关键门槛，再利用 D1-D7 核验证据是否充分、独立、持续并能够相互印证。

概括来说：六级负责回答“影响走到了哪里”，七维负责回答“这一判断有什么证据”。
