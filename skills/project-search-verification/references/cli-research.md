# CLI 主导的原生实时检索

## 实际影响证据调查（2026-09-26）

以“成果改变了什么”为查询问题，围绕同一成果版本组织：明确对象 → 谁真实采用 → 实际任务与结果 → 重复使用/领域嵌入。这个顺序是调查路径，不是所有成果必须依次经历的成熟度公式，也不在Search阶段判等级。

- **对象**：记录成果别名、版本、组成部件和时间窗口；基础模型论文、项目平台与具体成果分别追踪。命中同名词不算对象确认。
- **实际采用**：查询成果名称加方法使用、第三方复现、依赖、应用案例、工作流程等词；打开 Methods、仓库依赖/提交、部署记录。普通引用、星标、下载、媒体报道、授权专利仅证明对应事件，不能替代采用。
- **结果与持续性**：核实使用主体、任务、前后变化、时间、持续/重复记录、失败和成本；两篇转载不等于两个用户，一个联合研究的多家署名不等于多支独立使用团队。
- **领域边界**：小众领域按相关独立团队覆盖和作用深度描述，未知分母留空，不以用户绝对数低否定影响。科学发现可通过被后续研究用于解释、验证或推进发现来核验，不要求商业部署。
- **关系与方向**：合作方真实采用可作为使用证据，独立性另述；专业质疑、失败复现和副作用原样保留，关注和认可分开，不把负面传播计为正面作用。
- **基础能力与引领**：持续维护/日常嵌入不自动证明领域基础能力，另查跨方向依赖；新研究或工作方式需要前后流程与独立实践证据，不能由宣传的“颠覆性”直接推断。
- **后续调查**：优先查会改变结论的缺口。命中不足时更换别名、查文献链和独立使用方；按现有时间预算停止，并明确未覆盖对象/渠道，不做无结果的全称断言。

结构化分析沿用现有 Source、checks、research_records、模块 summary/limitations：在适用的原有列和说明内表达“谁—使用哪个版本—做何任务—得到什么变化—何时发生—来源关系—不能证明什么”。不要添加契约以外字段，不为填表补造主体、日期、指标或阈值。来源 quote 保持逐字引文；解释和推断放在结论与限制中。

专家综合修订版与长图补充：核查合作使用方是否具有自主选择和真实需求、是否存在互相出具证明的安排；不同单位名称既不能自动证明独立，也不能仅凭合作关系否定实际使用。区分形成时间、事件时间与材料日期；学术引用需追查是否用于解释、验证或推进后续研究。统计注明时段、对象与去重，机器人下载、重复测试和真实用户分开。领域依赖不要求跨领域用户；调查相关领域的作用深度和持续性。涉密或非公开使用只提示授权范围内补证，不要求公开上传，不因公开检索无记录就否定贡献。以上内容写入现有结论和限制，不在Search阶段判级。

当前运行方式：Docker 内 Codex CLI，codex-relay，原生 `web_search=live`。你负责读原文、决定查询、打开结果、追查引文和仓库、调整词语并判断是否获得有效证据；后台不替你选择检索词或来源。原采集脚本仅是你可调用的归档工具。

## 工作方式

1. 读取本次 `input.json`、`materials/*.txt` 和原始 Search 规范。追踪成果相关的论文、DOI、模型名称、参与团队、日期、样品和实验条件，区分具体成果与底层通用方法。
2. 分别调查 sota、prior_work、usage_media、github、indicator。多用原生 web search 的查询、打开与定位能力，尝试中英文、学术名称、标题、作者及文献链。根据实际结果继续追查，不以一轮检索作为完成条件。
3. 每个模块的搜索批次后立即执行 `python skill/scripts/research_session.py sync-web --module 模块名`。它直接从本次CLI工具事件读取真实查询和网址，不允许自己造日志。
4. 从返回编号中选择相关来源，执行 `python skill/scripts/research_session.py open Q001-S01 Q002-S01`。阅读 `research/primary-sources/` 下的原文。正文短、只有导航或验证码时继续用原生web查找出版方、作者主页、机构知识库等可追溯替代来源；搜索/打开新地址后再次sync，再归档新的编号。
5. 可用 `python skill/scripts/research_session.py status` 检查已查模块和正文获取状态。允许在本目录写工作笔记，不修改原件、skill、工具日志或采集回执。不读凭据、不发消息、不执行仓库代码。
6. 完成五模块调查后，返回完成摘要与检索边界。后续CLI基于你收集的材料生成完整结构化分析与表格；程序只校验出处、引文、日期和归档一致性。

研究时间上限30分钟，可在其中多轮检索和交叉核对。有效性优先，不设置必须找到正面证据的配额，不把无限重复请求当作质量。检索无命中与访问失败分别说明；背景论文不等于本成果独立采用，公开仓库不等于外部复用，关注不等于认可。
