## 自动化覆盖

后端9项测试分别在临时 SQLite 和隔离 MySQL `impact_test` 执行。原流程的关键词查询和工单创建改为管理员专用；新增用户固定表单的约束与持久化覆盖：

1. 未命中查询、工单去重与访客隔离；上传、任务、草稿、编辑版本冲突、审核发布、检索、撤回、历史和审计。
2. 注册无法提升为管理员、普通用户无法使用管理 API、无效密码与非可信来源拒绝。
3. 材料类型和空文本校验、损坏 PDF、DOCX 文本读取、原始材料权限；JSON 引用和演示标识保护。
4. 未配置适配器报错、任务重试、运行租约超时回收。
5. 两个并发 worker 对同一任务最多生成一份结果。
6. 查询中的百分号和下划线按字面量匹配。
7. 固定表单只返回所选项目；任务方向、说明、报告版本、固定模板完整保存；用户记录相互隔离。
8. 非法项目 ID、任意任务类型、过长文本、控制字符、额外 prompt 字段、草稿和撤回项目均被后端拒绝，不留下记录。
9. 联想从数据库查询，能找到初始20条之外的项目，且不泄露草稿。
