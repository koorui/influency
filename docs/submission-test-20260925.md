# 用户成果填报与工单交接测试

## 实现

- `/submit`：根据《代表性成果信息表-填报模版.docx》的八部分建立固定表单，另收集项目名称、AI参与和有来源的评审时间。
- 登录用户可上传文件、目录或ZIP；复用既有逐项解析与大小限制。服务器校验附件必须本人上传。
- 提交事务保存结构化表单、用户工单及明确标为“项目方自报”的原始表单材料。请求编号实现重复提交幂等；同编号不同内容返回冲突。
- 管理员受理单项评价时自动带入项目及材料；完整工作流可关联待处理工单，带入材料和时间，但项目/成果ID仍由管理员根据冻结范围确认，不自动猜测。
- 完整工作流回写待补充、失败、待审核状态；审核发布按明确工单关联返回结果。同名的其他成果填报不通过模糊匹配自动结单。
- 数据库迁移：0006成果表单、0007工作流工单关联，已应用本机MySQL。
